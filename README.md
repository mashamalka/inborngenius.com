# Inborn Genius

One-page site for Dr. Masha Malka.

## Files

- `index.html` — page markup
- `styles.css` — all styling
- `images/` — photos

## Editing

Open `index.html` to change copy or structure. Open `styles.css` to change colors, fonts, spacing. Drop replacement photos into `images/` (keep the same filenames, or update the `<img src>` in `index.html`).

## Hosting on GitHub Pages

1. Push this folder to a GitHub repo.
2. Repo → **Settings** → **Pages** → Source: `Deploy from a branch`, Branch: `main` / `(root)`.
3. Site goes live at `https://<your-username>.github.io/<repo-name>/`.
